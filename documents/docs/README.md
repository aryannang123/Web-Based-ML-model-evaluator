# Testing Reports

This folder contains the four test-report categories requested for the project:

1. [Unit Test Report](Unit_Test_Report.md) - full backend test discovery result from 2026-11-10.
2. [System Validation Report](System_Validation_Report.md) - local API health and Chromium, Firefox, and WebKit smoke checks from 2026-11-10.
3. [Code Coverage Report](Code_Coverage_Report.md) - existing focused line coverage evidence from 2026-11-07.
4. [Branch Coverage Report](Branch_Coverage_Report.md) - existing focused branch coverage evidence from 2026-11-07.

`coverage/` contains the original terminal screenshots and raw coverage command output. The unit and system reports state their observed results and limits; coverage evidence is explicitly dated separately because it was not rerun with the current validation.
